# Security reporting

Version 0.9.0 is not yet supported as a production release. Do not test against installations you do not own or administer. Send suspected vulnerabilities privately to your HTECH Digital Solutions contact or the site maintainer. After GitHub publication, the repository owner should enable GitHub Private Vulnerability Reporting and list the chosen contact channel here. No unverified email address is included.

Include the plugin version, WordPress/PHP versions, the affected permission level, a concise description, and a minimal sanitized report. Do not include passwords, tokens, production records, or actual customer contact details. See [the security review](docs/SECURITY-REVIEW.md) for scope and release blockers.
